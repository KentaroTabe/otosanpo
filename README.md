# 音さんぽ(OtoSanpo)— 画面を見ない散歩アプリ 試作

## アイデア概要

**音でそっと導く、画面を見ない寄り道散歩アプリ**

スマホを画面ではなく音で操る散歩アプリ。出発前に時間だけ決めれば、歩行中は短い効果音が普段通らない道への寄り道を提案する。時間が来たら音で知らせ、うなずきで帰路開始、首振りで延長を選択。帰路同意後は確認音がしばらく鳴り、その後は方向ビーコン音が自宅へ導く。移動履歴は端末内のみで学習し、通勤路は自動で除外される。

## 必要環境

- macOS + Xcode 15 以降(iOS 17 SDK)
- [XcodeGen](https://github.com/yonaskolb/XcodeGen)(`brew install xcodegen`)
- iPhone(iOS 17 以降)実機 — 位置情報・音声のフィールドテスト用
- AirPods(ヘッドフォンモーション対応: 第 3 世代 / Pro / Max 等)— ジェスチャ応答用

## セットアップ

```
brew install xcodegen
scripts/setup.sh
open OtoSanpo.xcodeproj
```

Xcode で Signing & Capabilities の Team を自分のアカウントに設定し、実機を選んで Run。

## 散歩テストの手順

1. 屋外でアプリを起動し、位置情報とモーションの権限を許可
2. 自宅(または出発点)で「自宅を現在地に設定」
3. 散歩時間を設定(既定 30 分)して「散歩を開始」
4. iPhone をポケットへ。AirPods は**外音取り込み**にする
5. 歩いていると、左右にパンした短い音が「そちらへ曲がると新しい道」と提案する(無視してよい)
6. 時間が来ると上行 3 音が鳴る。**うなずき=帰路開始 / 首振り=+10 分延長**
7. うなずくと確認音がしばらく繰り返され、その後は自宅方向から間欠的なピップ音が鳴る(近づくほど速くなる)
8. 自宅 40 m 以内で到着音が鳴り終了

普段の通勤・買い物の道を提案から外したい場合は、「通勤路の学習モード」を ON にしてその道を一度歩く。

## ディレクトリ構成

```
config/parameters.json   全数値パラメータ(閾値・時間・音の定義)
Sources/Core/            純粋ロジック(Foundation のみ)
Sources/Services/        位置・モーション・音・永続化のラッパ
Sources/App/             SwiftUI と統合コントローラ
Tests/                   Core のユニットテスト
docs/                    設計ドキュメント(01〜04)
scripts/                 setup / build / test
project.yml              XcodeGen 定義(*.xcodeproj は生成物)
```

## 既知の制限

- 初回ビルド未検証(上記)
- ジェスチャ閾値・音量・間隔は仮置き。フィールドテストで `config/parameters.json` を調整する前提
- 道路種別を把握しないため、交通量の多い道を避ける仕組みは未実装。安全に歩けるエリアでテストすること
- ビーコンの方向表現は左右パンのみ(真後ろの前後曖昧性あり。間隔変化で補完)
- 音はコード合成のサイン波(完成品でデザイン音源に差し替え)
