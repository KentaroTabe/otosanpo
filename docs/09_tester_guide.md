# 09. テスターの手順書(iPhone)

音だけで散歩を案内するアプリの試作です。**歩いている間は画面を見ません。**
スクリーンショットでは何も伝わらないので、実際に歩いてみてください。

配布は TestFlight なので、Mac も Xcode も要りません。招待を受け取って入れるだけです。

所要時間の目安: **準備 5 分 + 散歩 20〜30 分**。

歩く前に音だけ聴いてみたい場合は、開発者にそう言ってください。
音を並べたページをお渡しできます。

## 0. 用意するもの

| | 要否 | 補足 |
|---|---|---|
| iPhone(**iOS 17 以降**) | **必須** | GPS と音の左右を使うので、実機が要ります。**iOS 16 以前だと TestFlight に出てきません** |
| TestFlight アプリ | **必須** | **入れていなくて構いません**(手順 1 で入れます) |
| イヤホン | **必須** | 有線でもワイヤレスでも構いません |
| AirPods(第 3 世代 / Pro / Max) | あれば | うなずき・首振りで答えられます。**無くても参加できます** |
| 経路データ(`otosanpo-map.json`) | あれば | 開発者から受け取ります。無くても歩けます |

**AirPods は必須ではありません。** 使う場面はうなずき・首振りの応答だけで、
それは画面のボタンで置き換えられます。→ [AirPods を持っていない場合](#airpods-を持っていない場合)

**ただしイヤホンは要ります。** このアプリは「音がどちらから鳴るか」で方向を伝えるので、
iPhone のスピーカーだと左右がほとんど分かりません。有線イヤホンでも左右は分かるはずですが、
**まだ確かめられていません**(試したのは AirPods だけです)。分かりにくければ教えてください。

**歩く場所**: 車の少ない住宅街や公園まわりが向いています。
片側 2 車線以上の道が多い地域だと、横断を嫌う作りのため提案が減ります。

## 1. 入れる

**TestFlight を使ったことが無くて構いません。** Apple 純正の無料アプリで、
新しくアカウントを作る必要も、お金もかかりません。

1. **App Store で「TestFlight」を検索して入れてください**(既にあれば飛ばします)
   - お使いの Apple Account でそのまま使えます
   - **Mac ではなく iPhone の TestFlight** を使ってください。
     このアプリは iPhone 専用なので、Mac の TestFlight には出てきません
2. 開発者から届いた**招待メールかリンク**を iPhone で開いてください
   - 見当たらないときは迷惑メールを確認してください
   - 招待は**メールアドレス宛**に届きます。開発者に伝えたアドレスで受け取ってください
3. TestFlight が開くので「**受け入れる**」→「**インストール**」
4. 起動してください

**「開発元を信頼」の操作は要りません。** 更新が出ると TestFlight から通知が来て、
1 タップで入れ替わります。

> TestFlight は入れるためだけに使います。**歩いている間は開かないでください。**

## 2. 経路データを入れる(あれば)

経路データがあると、**実在する分岐から提案し、帰り道を道なりに案内する**ようになります。
無い場合は大まかな推測だけで動くので、「道の無い方向」を指すことがあります。

作るのは開発者側です。受け取ったら:

1. 送られた `.json` ファイルを AirDrop・メール・メッセージなどで iPhone に受け取ります
2. 共有メニューから「**"ファイル"に保存**」
3. 保存先に「**この iPhone 内 > OtoSanpo**」を選びます

**ファイル名は変えなくて構いません**(`名古屋市.json` のような都市名のままで読めます)。
保存先だけ間違えないでください。**iCloud Drive ではなく「この iPhone 内」**です。

アプリの画面に `地図: 名古屋市.json・半径20km・2026-08-28` のように出れば読めています。

| 表示 | 意味 |
|---|---|
| `地図: <ファイル名>・半径…` | 読めています |
| `地図: 未読込` | ファイルが置かれていません(保存先を間違えた可能性) |
| `地図: 読めません(<ファイル名>)` | 置かれているが壊れています。**開発者に知らせてください** |

> アプリを開いたまま保存した場合、**アプリに戻れば読み直します**。
> 変わらないときは一度アプリを完全に終了して開き直してください。

> 作るには**散歩の中心(自宅など)のだいたいの座標**が要るので、開発者から聞かれます。
> 渡したくなければ断って構いません。経路データ無しでも歩けます。

## 3. 散歩する

### 出発前

1. アプリを起動し、**位置情報**(アプリの使用中は許可)と**モーション**を許可してください
   - AirPods が無い場合、モーションは許可しなくても動きます
2. イヤホンを着けてください。AirPods なら**外音取り込み**にしてください
   (アプリからは切り替えられないので手で設定します)。**安全のため必ずお願いします。**
   外音取り込みの無いイヤホンなら、**片耳だけにする**などで周囲の音を確保してください
3. 出発点で「自宅を現在地に設定」。初回は「ここを自宅にして散歩を開始」でも構いません
4. 散歩時間を決めます(既定 30 分)
5. 「散歩を開始」を押します。**時間帯に応じた一言が出る**ので、閉じてポケットへ
6. 以後は画面を見ません
   - AirPods が無い場合だけ、**時間が来た音が鳴ったら一度だけ開きます**(下記)

### 歩いている間に鳴る音(5 種)

| 音 | 意味 | いつ |
|---|---|---|
| 上行する 2 音(880→1175 Hz) | **こちらへ曲がると新しい道** | 前方 35 m 以内の交差点に近づいた時。角に近づくほど大きくなります |
| 上行する 3 音 | **時間になった。帰りますか?** | 「今から帰れば時間ちょうど」の瞬間 |
| 下行する 2 音(長め) | **帰り道を始めました** | うなずいた直後 |
| 単発のピップ(440 Hz) | **帰る方向はこちら** | 帰り道の間。歩調に合わせて鳴り、家に近いほど大きくなります |
| 上行する 3 音(短い) | **到着** | 出発点の 10 m 以内 |

- **提案は無視して構いません。** 従わなくても叱られませんし、鳴り続けもしません
  (角が背後に回ると止まります)
- 曲がる案内は**音の鳴る方へ歩けば角に着く**ように作ってあります。
  角に近づくにつれて、音は曲がる先へ移っていきます
- 帰り道では、角も家も同じ音で鳴ります。
  連続して鳴っていれば「次の角」、とぎれとぎれなら「家の方向」です

### 時間が来たら

上行 3 音が鳴ったら、**帰るか・もう少し歩くか**を答えてください。
答え方は 2 つあり、**どちらでも動きは同じ**です。

**AirPods を着けている場合**(手を使いません)

- **うなずく** → 帰り道を始めます
- **首を横に振る** → 延長します(設定時間の 1/3。最大 2 回)

**画面から答える場合**(AirPods が無い / うなずきが検出されない)

1. iPhone をポケットから出してアプリを開きます
2. 一番上に「**時間になりました**」が出ているので、
   「**帰る**」か「**もう少し歩く**」を押します
3. 画面を閉じてポケットへ戻します

答えるまで 60 秒ごとに鳴り直します。**放っておいても勝手に帰らされることはありません。**
AirPods を外している間は鳴らさず、着け直した時に鳴り直します。

### AirPods を持っていない場合

**参加できます。** AirPods が要るのは上の「うなずき・首振り」だけで、
それは画面のボタンで置き換えられます。違いはここだけです。

| | AirPods あり | AirPods なし |
|---|---|---|
| 提案・帰り道の案内 | 音で鳴る | **同じ** |
| 左右・距離の伝わり方 | 音の向きと大きさ | **同じ**(イヤホンが要ります) |
| 時間が来た時の答え方 | うなずく / 首を振る | **画面のボタン** |
| 頭の向きの反映 | していません | していません |

**歩いている間に画面を開くのは、時間が来た時の 1 回だけです。**
それ以外は AirPods のある方と同じく、ポケットに入れたままで構いません。

> 「頭の向きを反映しない」のは今の作りの制限で、AirPods の有無とは関係ありません。
> **この点では差が付きません。**

## 4. 帰ってきたら

### 経路図を見る

アプリの「**前回の散歩(開発用)**」に、距離・時間・イベント数が出ます。
「経路図とイベントを見る」を開くと、歩いた道と**番号を振った案内**が地図になります。

- 灰色の線 = 端末に入っている経路データの道
- 太い線 = 実際に歩いた道
- 番号つきの丸 = 曲がる案内。**塗り = 曲がった / 白抜き = 曲がらなかった**
- 丸から伸びる矢印 = その案内が指した向き

**気になったことがあれば、この番号で教えてください。**
「3 番目の案内が道の無い方を指した」のように書いていただけると、原因をすぐ追えます。

### ログを書き出す

アプリの「フィールドログ > ログを書き出す」から、AirDrop などで開発者へ送ってください。
次のテストの前に「ログを消去」を押しておくと、回ごとの切り分けが楽になります。

TestFlight の「フィードバックを送信」からスクリーンショット付きで送ることもできます
(落ちた場合は自動で届きます)。

## 5. 感想の返し方

### 先にお読みください(プライバシー)

**フィールドログには緯度経度が入ります。ご自宅の座標も含まれます。**

- 送る相手は開発者本人に限ってください。**公開の場所に貼らないでください**
- 出したくなければ、送らなくて構いません。**文章の感想だけでも十分**役に立ちます
- **歩いた経路・自宅・ログがアプリから送られることはありません。**
  端末から出るのは、ご自分で書き出した時だけです

> **アプリが外と通信するのは、地図取得と、API キー設定時の周辺店舗候補取得です。**
> 散歩を開始した時に足りない分を自動で取得するほか、画面のボタンからも取得できます。
> 地図取得で送るのは**取得する区画(約 5 km 角)の番号**で、正確な位置は送りません。
> 周辺店舗候補を取得する時は、検索中心として現在地を Hot Pepper グルメサーチ API へ送ります。
> 地図が揃っていて、API キー未設定なら通信しません。

### 教えていただきたいこと

**うまく言葉にできなくて構いません。** 「なんか気持ち悪かった」で十分です。
ログと突き合わせれば原因は追えます。特に知りたいのは:

1. **音のする方へ歩けましたか。** 迷いましたか、自然に曲がれましたか
2. **左右が分かりましたか。** 分かりにくい場面はありましたか
3. **距離が分かりましたか**(音量で表しています)。角の手前で「ここだ」と確定できましたか
4. **うるさかったところ / 静かすぎたところ**
5. 帰り道は不安なく帰れましたか
6. **道の無い方向・私有地・危ない方向**を指した場面(あれば経路図の番号を添えてください)

## 6. 安全について

- **外音取り込みを必ず使ってください。** 音は断続的ですが、耳を塞ぐと環境音が聞こえにくくなります
- 提案は**地図の上で歩ける道かどうかを見ているだけ**で、交通量や工事は考えていません。
  **従うかどうかはご自分で判断してください**
- 夜間・雨天・不慣れな土地での初回テストは避けてください
- 画面を見ながら歩かないでください(そもそも見ない作りです)

## 7. うまくいかないとき

| 症状 | 見るところ |
|---|---|
| 招待メールが見つからない | 迷惑メールを確認してください。招待は**メールアドレス宛**で、App Store の検索には出てきません。**メールが無くても、そのアドレスでサインインした iPhone の TestFlight を開けば一覧に出るはずです** |
| TestFlight に出てこない / 「利用可能なビルドがありません」と出る | **iPhone が iOS 17 以降か**を確かめてください(設定 → 一般 → 情報)。iOS 16 以前だと配信されません。**開発者側からは「配信できていない」ようにしか見えない**ので、この場合は教えてください |
| TestFlight のアカウントが違う気がする | 招待は**開発者に伝えたアドレスの Apple Account** に届きます。iPhone がそのアカウントでサインインしているか確認してください |
| Mac の TestFlight に出てこない | 正常です。**iPhone 専用アプリ**なので Mac には出ません |
| 音が全く鳴らない | 画面の「音声: 稼働 / 停止」を見てください。停止ならイヤホンを繋ぎ直します。「earcon の試聴」で単発の音を確かめられます |
| 左右が分からない | イヤホンを使っていますか。**スピーカーだと左右はほぼ分かりません** |
| 時間が来ても何も鳴らない | 設定時間より早く鳴ることがあります(「今から帰れば時間ちょうど」で鳴るため)。アプリを開いて「時間になりました」が出ていないか確かめてください |
| 提案が 1 度も鳴らない | 画面の「地図:」表示を見てください。`未読込` なら手順 2 です。初回の散歩は全方向が未踏で「直進が最良」になりやすく、鳴らないことがあります |
| 保存したのに `地図: 未読込` のまま | 保存先が **iCloud Drive** になっていないか確かめてください(正しくは「この iPhone 内 > OtoSanpo」)。それでも変わらなければアプリを完全に終了して開き直してください |
| 案内が道の無い方を指す | 地図が入っているか確かめてください。入っていて起きるなら**不具合**です。経路図の番号を添えて教えてください |
| うなずきが効かない | AirPods がモーション対応モデルか、画面に「モーション ○○ Hz」が出ているかを見てください。効かなければ**画面の「時間になりました」から答えてください**(同じ動きになります) |
| 到着音が鳴らない | 設定した出発点と実際の到着位置がずれている可能性があります。開発者へ連絡してください |
| 帰り道の案内が来ない | 地図が入っていないと道なりの案内は出ず、家の方向を直線で指す音だけになります |

## 8. いまの状態(期待値の調整)

**試作であって製品ではありません。** 分かっている制限:

- 音は合成したサイン波で、**デザインされた音ではありません**
- **首を振っても音は動きません。** 頭の向きは反映していません
- 前後は聴き分けられません。真後ろは音色を暗くして代わりにしています
- 首を振っていないのに「振った」と判定されることが 1 割ほどあります(いまは直していません)
- 60 分を超える散歩や、長時間ポケットに入れたままの動作はあまり確かめられていません
- アイコンは仮のものです

**それでも「音の鳴る方に歩くと面白い散歩になるか」を確かめたくて作っています。**
おかしいと思ったことは、遠慮なく教えてください。
