# 11. テスターの手順書(Android)

音だけで散歩を案内するアプリの試作です。**歩いている間は画面を見ません。**
スクリーンショットでは何も伝わらないので、実際に歩いてみてください。

**配布のページから APK を落として入れるだけ**です。ストアからは入れません。

所要時間の目安: **準備 5〜10 分 + 散歩 20〜30 分**。

> **重要: この Android 版(1.1)は、開発者の手元の実機では 1 度も動かせていません。**
> ビルドが通ることしか確かめられていないので、**最初は「起動して 5 分歩く」だけ**を
> お願いします。落ちる・鳴らない・進まない — どれが起きても、それ自体が結果です。
> **うまくいかなくても、あなたのせいではありません。**

## 0. 用意するもの

| | 要否 | 補足 |
|---|---|---|
| Android 端末(**Android 10 以降**) | **必須** | GPS を使います。**Android 9 以前には入りません** |
| イヤホン・ヘッドフォン | **必須** | 有線でもワイヤレスでも構いません |
| APK | **必須** | 配布のページから落とします(手順 1) |
| 経路データ | 自動 | **APK に同梱されています。** 何もしなくて構いません |

**イヤホンは必ず要ります。** このアプリは「音がどちらから鳴るか」で方向を伝えるので、
端末のスピーカーだと左右がほとんど分かりません。

**歩く場所**: 車の少ない住宅街や公園まわりが向いています。

## 1. 入れる

1. **配布のページを端末で開き、お住まいの地域の APK を 1 つ**選んで落とします
   - `otosanpo-android-kanazawa.apk` — **金沢市**とその周辺
   - `otosanpo-android-nagoya.apk` — **名古屋市**とその周辺
   - `otosanpo-android.apk` — 上以外の地域(地図なし。**それでも歩けます**)
2. 落とした APK を開いてください
3. 「提供元不明のアプリ」「この提供元のアプリを許可」を求められたら許可してください
   - **開発中のアプリなのでストアには出していません。** そのための確認です
4. インストールして起動してください

> **更新は自動では来ません。** 新しい版が出たら、また同じようにページから入れ直してください。

## 2. 経路データを確認する

経路データがあると、**実在する分岐から提案し、帰り道を道なりに案内する**ようになります。
無い場合は大まかな推測だけで動くので、「道の無い方向」を指すことがあります。

**アプリを起動して、画面の「地図:」の行を見てください。**

- `地図: 半径20km・2026-08-28` のように出ていれば**入っています。何もしなくて構いません**
- `地図: 未読込` なら入っていません(地図なしの APK を選んだ場合はこれで正常です)

> 都市名の入った APK(`otosanpo-android-kanazawa.apk` など)を選んだ場合、
> **その都市の経路データは最初から入っています。**
>
> **iPhone 版と違い、Android 版は地図を自分で取りに行きません。**
> 入っているのは APK に同梱した分だけです。

### 自分の地域の APK が無い場合

**そのまま歩けます。** 経路データが無いと、実在する分岐ではなく大まかな推測で
提案するので、「道の無い方向」を指すことがあります。**それ自体が結果**なので、
気になった場面を教えてください。

お住まいの地域の経路データが欲しい場合は、下記の Issues でその旨お知らせください。

> 作るには**散歩の中心(自宅など)のだいたいの座標**が要ります。
> **Issues は公開の場所なので、自宅の座標は書かないでください。**
> 市区町村名だけで構いません。

## 3. 散歩する

### 出発前

1. アプリを起動し、**位置情報**・**身体活動**・**通知**を許可してください
   - 位置情報は「アプリの使用中のみ」で足ります
   - 身体活動は歩調(音の間隔を歩みに合わせる)に使います
   - 通知は常駐の表示に使います。**Android では画面を消したまま動かすのに要ります**
2. イヤホンを着けてください。**外音取り込みがある機種はオンにしてください**(安全のため)。
   無い機種なら、**片耳だけにする**などで周囲の音を確保してください
3. 出発点で「自宅を現在地に設定」。初回は「ここを自宅にして散歩を開始」でも構いません
4. 散歩時間を決めます(既定 30 分)
5. (任意)**音楽スポット**を使うなら、下の節を読んで曲を選んでください
6. 「散歩を開始」を押します。**時間帯に応じた一言が出る**ので、閉じてポケットへ
7. 以後は画面を見ません

### 音楽スポット(任意・2026-09-19 から)

**街のどこかに曲が置いてあり、近づくほど大きく鳴る**、という遊びです。

1. 「**音楽スポットに使う曲を選ぶ**」を押すと、端末の曲を選ぶ画面が出ます
   - **選べるのは 1 曲だけ**です。選び直すと前の曲は消えます
   - 選んだ曲は**アプリの中へ写します**(元のファイルは触りません)
   - **m4a / mp3 / wav / flac** が使えます。選べない形式は「読み込めませんでした」と出ます
2. 「**音楽スポット: 切**」を押して「入」にします
3. 散歩を始めると、出発した地点から**散歩時間に応じた距離**に 1 箇所置かれ、
   そこから鳴り始めます

- **左右**と**音量**で場所を表します。**近づくほど大きく**なります
- **曲が鳴り終わったらそこまで**です。同じ散歩で鳴り直すことはありません
- しばらく歩くと「**別の場所へ移しますか**」という短い 3 音(下がって上がる)が鳴ります。
  **音量↓で移る / 音量↑・放っておけばそのまま。** 断るほど、次に聞かれるまでの間隔が
  倍々に伸びます(しつこくしないためです)
- **案内音(提案・帰路)は曲と重ねて鳴ります。** 曲は小さくなりません。
  **案内が聞き取りにくければ、そこを教えてください**(まだ調整していません)

> iPhone 版では「近づくと下の方から鳴る」「遠いと広がって聞こえる」手がかりも載せていますが、
> **Android にはその仕組みがありません**(左右と音量だけです)。ここは版による違いです。

### 歩いている間に鳴る音(5 種)

| 音 | 意味 | いつ |
|---|---|---|
| 上行する 2 音(880→1175 Hz) | **こちらへ曲がると新しい道** | 前方 35 m 以内の交差点に近づいた時。角に近づくほど大きくなります |
| 上行する 3 音 | **時間になった。帰りますか?** | 「今から帰れば時間ちょうど」の瞬間 |
| 下行する 2 音(長め) | **帰り道を始めました** | 「帰る」を選んだ直後 |
| 単発のピップ(440 Hz) | **帰る方向はこちら** | 帰り道の間。歩調に合わせて鳴り、家に近いほど大きくなります |
| 上行する 3 音(短い) | **到着** | 出発点の 10 m 以内 |

- **提案は無視して構いません。** 従わなくても叱られませんし、鳴り続けもしません
- 曲がる案内は**音の鳴る方へ歩けば角に着く**ように作ってあります
- 帰り道では、角も家も同じ音で鳴ります。
  連続して鳴っていれば「次の角」、とぎれとぎれなら「家の方向」です

### 時間が来たら — **音量ボタンで答えます**

上行 3 音が鳴ったら、**ポケットに入れたまま**答えられます。

- **音量↓ = 帰る**
- **音量↑ = もう少し歩く**(設定時間の 1/3。最大 2 回)

画面を開くと**一番上に「時間になりました」が出て**、「帰る」「もう少し歩く」のボタンが並びます。
**音量ボタンが効かなければそちらを押してください。** どちらで答えても動きは同じです。
(この 2 つのボタンは、問いかけの間だけ出ます)

> 音量ボタンは**アプリを画面に出している間だけ**効きます。
> ポケットの中で画面が消えていると反応しないので、その時は画面を点けてから押してください。
> **ここは特に感想を聞きたいところです**(そもそも実用になるのか、まだ分かっていません)。

答えるまで 60 秒ごとに鳴り直します。**放っておいても勝手に帰らされることはありません。**

## 4. 帰ってきたら

### 記録を見る

アプリの「**前回の散歩**」に、距離・時間・イベント数と、
案内の終わり方の内訳(曲がり終えた / 従わなかった / 角から離れた)が出ます。

### ログを渡す

**左上の三本線(≡)→「フィールドログ」**を開き、
「**ログをダウンロードへ書き出す**」を押すと、端末の「ダウンロード」に
`otosanpo-field-log-<日時>.tsv` ができます。標準のファイルアプリから共有できます。

次のテストの前に「ログを消去」を押しておくと、回ごとの切り分けが楽になります。

## 5. 感想の返し方

### 連絡は Issues へ

気づいたことは **[Issues](https://github.com/KentaroTabe/otosanpo/issues)** へどうぞ。
GitHub のアカウントがあればそれだけで書けます。

**この手順書に開発者のアドレスは載せていません。** ログには自宅の座標が入るので、
公開の場所に宛先を置かない方針です。**文章の報告は Issues で十分届きます。**

端末の機種と Android のバージョンを添えていただけると、絞り込みが早くなります。

### 先にお読みください(プライバシー)

**フィールドログには緯度経度が入ります。ご自宅の座標も含まれます。**

- **Issues にログを貼らないでください。公開の場所です。** 文章の報告だけにしてください
- ログをお送りいただくのは、**開発者と直接やり取りのある方だけ**にしています。
  配布のページから入れた方は、**文章の報告だけ**お願いします
- 出したくなければ、送らなくて構いません。**文章の感想だけでも十分**役に立ちます
- アプリは通信を一切しません。記録が端末から出るのは、ご自分で書き出した時だけです

### 教えていただきたいこと

**うまく言葉にできなくて構いません。** 「なんか気持ち悪かった」で十分です。

1. **そもそも動きましたか。** 落ちませんでしたか、音は鳴りましたか(**今回はここが最重要**)
2. **音のする方へ歩けましたか。** 迷いましたか、自然に曲がれましたか
3. **左右が分かりましたか**
4. **距離が分かりましたか**(音量で表しています)
5. うるさかった / 静かすぎた場面
6. **音量ボタンでの応答は使いやすかったですか**
7. 道の無い方向・私有地・危ない方向を指した場面

## 6. 安全について

- **外音取り込みがあれば使ってください。** 耳を塞ぐと環境音が聞こえにくくなります
- 提案は**地図の上で歩ける道かどうかを見ているだけ**で、交通量や工事は考えていません。
  **従うかどうかはご自分で判断してください**
- 夜間・雨天・不慣れな土地での初回テストは避けてください
- 画面を見ながら歩かないでください(そもそも見ない作りです)

## 7. うまくいかないとき

**まだ 1 度も実機で動かせていないので、ここに無い症状も起こりえます。**
その場合は、起きたことをそのまま教えてください。

| 症状 | 見るところ |
|---|---|
| インストールできない | 「提供元不明のアプリ」を許可しましたか。**Android 9 以前には入りません**(設定 → デバイス情報で確認できます) |
| 起動して「設定ファイルを読み込めません」と出る | APK の不備です。**Issues で教えてください**(作り直します) |
| 音が鳴らない | イヤホンの接続を確かめてください。**左上の三本線(≡)→「提案音 左 / 右」**を押すと単発の音が鳴ります |
| 左右が分からない | イヤホンを使っていますか。**スピーカーだと左右はほぼ分かりません** |
| 提案が 1 度も鳴らない | 画面の「地図:」表示を見てください。`未読込` なら地図なしの APK です(その場合でも鳴りますが、精度は落ちます)。初回の散歩は全方向が未踏で「直進が最良」になりやすく、鳴らないことがあります |
| 自分の地域の APK が無い | 地図なしの `otosanpo-android.apk` でも歩けます。欲しい場合は **Issues で市区町村名だけ**お知らせください(**自宅の座標は書かないでください**)。その地域を入れた APK を作れます |
| 現在地が取れない | 位置情報の許可を確かめて、屋外で空の見える場所で数十秒待ってください |
| 画面を消すと止まる | 通知に「散歩中」が出ていますか。機種によっては**電池の最適化から除外する**必要があります |
| 音量ボタンが効かない | アプリを画面に出した状態でのみ効きます。画面を点けてから押してください。効かなければ画面の一番上に出る「帰る」「もう少し歩く」で答えられます |

## 8. いまの状態(期待値の調整)

**試作であって製品ではありません。** 分かっている制限:

- **開発者の手元に Android 実機がありません。** この版(1.1)も画面すら見ていません。
  **ここを確かめたいのが今回です**
- 音は合成したサイン波で、**デザインされた音ではありません**
- **首を振っても音は動きません。** 頭の向きは反映していません
  (Android にはヘッドフォンの向きを取る仕組みが無く、iPhone 版だけの機能です)
- 前後は聴き分けられません。真後ろは音色を暗くして代わりにしています
- 音楽スポットは**左右と音量だけ**です。iPhone 版にある仰角・広がりはありません
- 歩いた道を図で見る画面は、まだありません(数字だけです)
- 画面を消したままの長時間の動作は確かめられていません

**それでも「音の鳴る方に歩くと面白い散歩になるか」を確かめたくて作っています。**
おかしいと思ったことは、遠慮なく教えてください。
